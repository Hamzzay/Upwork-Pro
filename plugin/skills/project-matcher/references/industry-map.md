# Industry map

The job's industry decides the first pool. Use the library's Industry tags, and the project overview when a project has no industry tag. If Upwork Pro has an industry not listed here (its Industries page lists the related ones too), treat it as its own industry with no related industries.

## Industries

Healthcare · Dental · Insurance · Legal · Real estate · Construction · Home services · Logistics · E-commerce / retail · Education · Recruitment / HR · Finance / accounting · Hospitality · Automotive · Marketing / agency · Beauty / salon · Sports · Event management · Social

If the job's industry is not on this list (for example sports, nonprofit, manufacturing), match on project overviews: projects whose overview places them in that industry count as Same industry.

## Related industries

A project in a related industry goes in the Related pool, ranked after Same industry.

| Job industry | Related project industries |
| --- | --- |
| Dental | Healthcare |
| Healthcare | Dental, Insurance (health insurance, prior authorization, claims) |
| Insurance | Healthcare when the job concerns health insurance; Finance / accounting otherwise |
| Legal | Insurance (claims), Real estate (leases, compliance) |
| Real estate | Construction, Home services, Legal (property compliance) |
| Construction | Home services, Real estate |
| Home services | Construction, Real estate |
| Logistics | E-commerce / retail |
| E-commerce / retail | Logistics, Marketing / agency |
| Education | Recruitment / HR |
| Recruitment / HR | Education |
| Finance / accounting | Insurance |
| Hospitality | Beauty / salon (bookings), E-commerce / retail |
| Automotive | Home services (field sales and service) |
| Marketing / agency | E-commerce / retail |
| Beauty / salon | Hospitality (bookings) |
| Sports | Event management, Hospitality (venue and booking) |
| Event management | Sports, Hospitality |
| Social | Marketing / agency |

Relations are one step only. A Related project never outranks a Same industry project that clears the minimum tag score.
