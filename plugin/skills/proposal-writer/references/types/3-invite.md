# Type 3. Invite

**Chosen when:** the client invited the profile. Signals in `../type-selection.md`.
**Length:** 100 to 160 words.

## Structure

1. **Greeting.** "Hi [name], thanks for the invite." If no name is given, start with the approach.
2. **Approach.** Two or three sentences on how we would tackle their project.
3. **Similar projects line.** One sentence naming two or three similar projects.
4. **Link lines.** One per named project.
5. **Close.** One line with a concrete next step.
6. **Signature** from the profile record.

Invites stay light. The client already chose to look at us, so the named projects with links carry the proof. No detailed project descriptions.

## Approach rules

1. Two or three sentences, anchored on the client's main pain from their post.
2. The first sentence must make the client feel understood, since it shows in the preview.
3. Commit to their stack. Name the tools they named.
4. Say what we would do first and why it matters to them.
5. Sound like a person talking. No lecture, slogan or sales line.

## Similar projects line

1. One sentence, 20 to 30 words, in its own paragraph after the approach.
2. Names the type of system and context that match this job, then names two or three similar projects.
3. Only true claims. Numbers only from the library or the profile's allowed stats.
4. Plain and confident, not a brag.

## Link lines

Directly below the similar projects line, one line per named project:

```
Project Name – [link]
```

## Close rules

1. One line, 9 to 11 words.
2. A concrete next step, such as a short call this week. Invites are warm, so the close can be more direct than Type 1.
3. No question mark, no easy out, no banned phrases.

Example: "Let's book a 20 minute call this week to plan rollout."

## Estimates

If the client asks for timeline or budget, apply the estimate answer rule in `../modules.md`.

## Do not

1. Do not write detailed project descriptions; the link lines carry the proof.
2. Do not open with a pitch about us after the greeting; open with their pain.
3. Do not thank them twice or sound grateful to be picked. One "thanks for the invite" is enough.

## Sample

Structure illustration only. Project facts in samples are not verified; take every project fact from the library.

Job: invite to build an AI voice receptionist for a three location dental group. Client mentions after hours calls going to voicemail.

```
Hi Daniel, thanks for the invite.

For your three locations, I'd set up the voice agent on Retell to triage after hours calls first, since those are often emergency patients who book with whoever answers. Routine bookings and reminders come next, synced with each location's calendar so no slot gets double booked.

I've built AI voice agents for appointment based businesses, including DentAI Call and Apex Windows, where every missed call means a lost customer.

DentAI Call – [link]
Apex Windows – [link]

Let's book a 20 minute call this week to plan rollout.

[Signature from profile record]
```
