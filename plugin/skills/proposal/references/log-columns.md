# Job Log columns

One row per job. Step 4 creates the row; step 10 completes it. Write by header name.

## Existing columns (written at step 4)

| Column | Value |
| --- | --- |
| Date Screened | Today, YYYY-MM-DD |
| Upwork Profile | Blank at step 4; filled at step 10 |
| Job Title | From the job |
| Job Description | Full description |
| Job URL | Normalized link |
| Posted | As shown, or "Not shown" |
| Job Type | Hourly or Fixed-price |
| Budget | Rate range or amount, or "Not stated" |
| Length and Hours per Week | As shown |
| Experience Level | As shown |
| Service Category | Short service label(s) |
| Required Skills and Tools | Named tools |
| Client Country | As shown |
| Payment Verified | Yes, No or Not shown |
| Client Rating (Reviews) | e.g. 4.96 (109) |
| Jobs Posted | Number |
| Hire Rate | Percent |
| Total Spent | Amount |
| Hires | Number |
| Avg Spend per Hire | Amount |
| Avg Hourly Paid | Amount; note "(calculated)" if derived |
| Member Since | Date |
| Proposals | Band as shown |
| Interviewing | Number |
| Invites Sent | Number |
| Connects Cost | Number |
| Sample Match | Matched project names, or "None" |
| Verdict | PASS, FLAG or FAIL |
| Fail Reasons | Each fail with its value, separated by " \| " |
| Flag Reasons | Each flag with its value, separated by " \| " |
| Rule Codes | e.g. F2, G3, G14; D1 for a duplicate job |
| Proceeded | Yes or No |
| Override Reason | Quick pick plus note |
| Proposal Sent Date | Left for the submitter |
| Outcome | Left for the submitter |
| Notes | Anything unusual; "Duplicate of row N (profile, date)" when resubmitting |

## Proposal columns (written at step 10)

Add these headers to the right of `Notes` if they do not exist yet. If they are missing and cannot be added, write the proposal fields into `Notes` instead and say so.

| Column | Value |
| --- | --- |
| Proposal Type | 1 to 8 with name |
| Signals | Short summary of non fallback signals |
| Job Tags | Tags assigned to the job |
| Projects Shown | Five shortlisted names with scores |
| Projects Chosen | The one or two picked |
| Rate Bid | Final rate or fixed amount |
| First Line | First line of the cover letter |
| Word Count | Cover letter word count |
| Closes on Question | Yes or No |
| Cover Letter | Final text |
| Screening Answers | Final text |
| Boost | Left for the submitter |
| Connects Spent | Left for the submitter |

## Override quick picks

Invite · Strong client history · Strong project fit · Low workload · Other (with a note)
