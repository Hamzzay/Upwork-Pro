# Verification checklist

Run every item. Mark pass or fail. Rewrite once on fail, then flag.

## Client instructions

- [ ] Every explicit ask and screening question answered, in order
- [ ] Required words or format used exactly
- [ ] Portfolio links included if asked
- [ ] Pricing asks handled by the quote rule and flagged

## Accuracy

- [ ] Every tool the client named appears correctly, with no alternative offered
- [ ] Every project is allowed for this profile and uses its link in the set order: landing page or mobile, then system, then case study, then staging (case study and staging flagged)
- [ ] No email address, phone number, contact page or social handle appears anywhere in the proposal
- [ ] Every claim traces to a stored project fact
- [ ] Every number traces to a verified result
- [ ] No white label work mentioned

## Writing rules

- [ ] First two lines use a detail from this post and say something useful
- [ ] At least one insight the client did not state
- [ ] No banned phrases and no feature list longer than three items
- [ ] No dashes, no emojis
- [ ] Length within the type's range
- [ ] Closes on one specific question or a concrete first step
- [ ] Signature matches the profile record
- [ ] Profile rules followed (for example no timeline or budget for Hassan unless asked)
