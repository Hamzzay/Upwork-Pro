# Type 6. Small fix or quick task

**Chosen when:** a small, clearly bounded task.
**Length:** 50 to 100 words.

## Structure

1. **Likely cause** in one line.
2. **The fix** in one or two lines.
3. **Availability** to start now.
4. **Close.** One question to confirm access or scope.
5. **Signature** from the profile record.

A project link only if it proves the exact fix.
